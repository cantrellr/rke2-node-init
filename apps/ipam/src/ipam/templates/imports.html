Import Behavior

  • Rows are normalized into sites, networks, and IP assignments.
  • Repeated blank cells are filled down for site and subnet context.
  • Each new upload replaces earlier imported rows from the same workbook filename.
  • Validation reruns after every import to detect duplicate IPs and subnet overlaps.
  • The export endpoints always reflect the current application database.
